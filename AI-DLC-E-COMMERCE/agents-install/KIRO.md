# Kiro Setup

Kiro is one of the supported AI-enabled harness options for this project. You can use another harness instead; see [SETUP.md](../SETUP.md) for the AI-DLC installation and configuration steps.

## Install and sign in

1. Install Kiro using the instructions at [kiro.dev](https://kiro.dev/).
2. Sign in with an account you are authorized to use:

```bash
kiro-cli login
```

3. Open the project in Kiro and follow [SETUP.md](../SETUP.md) to configure and verify AI-DLC.

To sign out when finished, run:

```bash
kiro-cli logout
```
